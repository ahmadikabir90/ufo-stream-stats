# ufo-stream-stats

Public OBS overlay for **simulated** trading stats. Not live trading.

## Add it in OBS

1. In OBS, add a **Browser** source.
2. URL: `https://ahmadikabir90.github.io/ufo-stream-stats/`
3. Width **360**, height **520**.
4. Place the source over a corner of the chart.

The page background is transparent. Stats refresh about every 30 seconds. GitHub Pages can lag a minute or so behind a push.
